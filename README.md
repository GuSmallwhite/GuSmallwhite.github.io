# 顾的博客

从旧博客恢复的 Hexo 源码，包含 50 篇文章和极简主题。源码已备份到 GitHub source 分支，生成页面发布到 main 分支。

## 本地阅读与写作

在本文件所在目录打开终端：

```sh
npm ci
npm start
```

浏览器访问 http://localhost:4000 。本次已经安装好依赖，以后直接运行 `npm start` 即可。

文章在 `source/_posts/`，可用任何纯文本编辑器修改。新建文章：

```sh
npm run new -- "文章标题"
```

修改完成后运行 `npm run build`，生成的网站位于 `public/`。
